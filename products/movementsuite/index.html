MovementSuite (v1.2.0) - User Guide

By Twikia Studios · © 2026 Twikia Studios · Online User Guide

Setup

Step 1: Add Movement Suite to Your Character

Copy MovementSuite into Plugins/, enable it, and drag Movement Suite onto your ACharacter to provision and wire all enabled modules automatically.

Step 2: Assign Input Mapping Context & Actions

Select each enabled module component (such as SprintState or SlideState) and assign your InputMappingContext and InputAction in Details.

End of Setup

Your character now strings together high-speed sprints, slides, grapples, wall runs, dashes, bullet-time, and camera feedback out of the box. Everything below lets you enable only what your game needs, style HUD combos, and wire custom audio/VFX.

Extras A - Unified & Per-Module Event Callbacks

OnAnyMovementEntered

Fires whenever any active movement state starts.

OnAnyMovementExited

Fires whenever any active movement state finishes.

OnAnyMovementFired

Fires when impulse abilities trigger (dashes, jumps).

OnComboUpdated

Broadcasts combo streak count and timer for HUD animations.

Sprint OnStateEntered

Per-module hook for sprint FOV and audio.

Slide OnStateEntered

Per-module hook for slide sparks and dust.

Extras B - Ground, Wall & Grapple Triggers

TryEnterSprint

Starts sprinting and ramps ground speed smoothly.

ExitSprint

Blends speed smoothly back to baseline walk.

TryEnterSlide

Boosts into a frictionless slope-responsive slide.

ExitSlide

Restores ground friction and arms cooldown.

TryEnterDive

Drives fast downward acceleration mid-air.

TryEnterFastFlying

Engages high-speed steered flight with brief time dip.

ExitFastFlying

Exits flight cleanly and releases time dilation.

TryEnterWallRun

Attaches to a valid vertical wall face.

ExitWallRun

Releases the wall with optional cooldown.

TryEnterGrapple

Traces from crosshair to latch and pull/swing.

TryEnterGrappleAtPoint

Latches directly onto a known world point.

ExitGrapple

Detaches active grapple and hides the tether spline.

UpdateSplineEndpoints

Syncs dynamic rope endpoints in world space.

Extras C - Jumps, Dashes, Time Slow, Combo & Camera FX

TryExecuteJump

Dispatches Sprint, Slide, Wall, or regular Jump automatically.

TryEnterJetpack

Applies sustained aerial lift while fuel lasts.

TryAirDash

Triggers a snappy mid-air burst with lift.

TryBackDash

Fires an instant backward evasive dodge.

TryForwardDash

Charges forward and knocks nearby targets aside.

ToggleTimeSlow

Toggles resource-managed world bullet-time.

StepCameraFX

Interpolates roll, FOV, and HUD slosh values.

BindCameraTargets

Links SpringArm and Camera to CameraFX manually.

StepCombo

Advances combo timer decay cleanly.

ResetCombo

Clears active combo multiplier and recent state history.

Extras D - State Queries, HUD Readouts & Contracts

IsStateActive

Checks if any UMovementBaseComponent module is active.

IsOnCooldown

Checks if an ability's cooldown timer is active.

GetComboNumber

Reads current combo streak multiplier.

GetComboTimeLeft

Reads seconds left before the combo expires.

GetDecayRateForState

Returns how fast each state drains combo time.

GetCurrentFuel

Reads remaining Jetpack fuel fraction.

GetFlyTime

Reads elapsed Fast Flying duration.

GetUiSloshAcceleration

Returns bounded parallax offset for HUD sway.

GetCurrentFOV

Reads live blended camera FOV.

CheckIfNearWall

Checks for a runnable vertical wall near the player.

GetCurrentWallNormal

Reads active wall surface normal.

GetGrapplePoint

Reads current grapple world anchor point.

IMovementCharacterContract

Supply custom view origin, forward aim, and input.
