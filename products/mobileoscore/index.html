Demo Console Commands & Deep-Link Harness

No setup needed: Open CPP/MobileOSCoreDemo.uproject on desktop or Android and run mosc.* console commands (with scheme mobileoscoredemo://). All functionality will work out of the box in the demo for testing.
Console CommandAction
mosc.perm / mosc.exact / mosc.settingsCheck or request notification permissions and exact-alarm settings
mosc.schedule ... / mosc.cancel / mosc.cancelallSchedule or cancel persistent local notifications with optional deep links
mosc.badge / mosc.clearUpdate app launcher badges or clear active notifications
mosc.consumeConsume cached cold-start deep links and trigger your navigation event
mosc.alert / mosc.share / mosc.toastOpen native OS modal dialogs, share sheets, or toast banners
mosc.battery / mosc.thresholdsRead live battery charge/temperature telemetry or set thermal warning thresholds

Setup

Step 1: Enable Plugin & Resolve Mobile OSCore Subsystem

Copy MobileOSCore into Plugins/, enable MobileOSCore (and AndroidPermission), set Android Min SDK 26+, and fetch Mobile OSCore Subsystem in Blueprint.

Step 2: Request Runtime Notification Permissions

Bind On Notification Permission Result and call Request Notification Permission before scheduling notifications.

Step 3: Schedule Notifications & Consume Deep Links

Call Schedule Local Notification for delayed reminders and call Consume Cold Start Deep Link when your startup menu initializes.

End of Setup

Your mobile project now schedules reboot-safe reminders, handles deep links reliably from cold start, and reads thermal/battery state natively in Blueprint. Everything below explains native UI helpers, delegate hooks, and Android manifest setup.

Extras A - OS Event Callbacks

OnNotificationPermissionResult

Fires after permission prompt or settings flow completes.

OnDeepLinkReceived

Fires on cold-start consume, warm link, or notification tap.

OnAlertButtonClicked

Returns which native alert button index the player tapped.

OnBatteryStateChanged

Broadcasts battery charge level, Celsius temp, and alerts.

Extras B - Native UI, Deep Links & Android Intent Filter

ShowNativeAlertDialog / ShareSheet / Toast

Invoke native Android UI dialogs, shares, and toasts safely.

ConsumeColdStartDeepLink & ParseURIQueryParameters

Decode deep-link parameters and inspect battery telemetry.

Optional Custom URI Scheme (Project Settings)

Add this intent filter inside Project Settings -> Platforms -> Android -> Extra Activity Settings to route custom mygame:// links directly into your app:

ExtraActivitySettings="<intent-filter>\n<action android:name=\"android.intent.action.VIEW\"/>\n<category android:name=\"android.intent.category.DEFAULT\"/>\n<category android:name=\"android.intent.category.BROWSABLE\"/>\n<data android:scheme=\"mygame\"/>\n</intent-filter>"

Extras C - Cross-Platform Iteration Safety

PlatformRuntime Behavior
AndroidExecutes all notification, badge, deep-link, native UI, and battery features with 16 KB ELF alignment
Win64 / Editor / iOSProvides safe no-op stubs so multi-platform PIE testing works without #if PLATFORM_ANDROID clutter
