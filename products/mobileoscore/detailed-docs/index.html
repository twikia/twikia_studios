1. Architecture & Feature Breakdown

Notifications, Badges & Deep Links

UMobileOSCoreSubsystem exposes reboot-persistent local notifications (with Android 13+ POST_NOTIFICATIONS and Android 12+ exact-alarm permission helpers), launcher icon badge clearing, and unified cold-start / warm deep-link URI capture and query-parameter decoding.

On Win64 Editor and non-mobile targets, all methods execute safe no-op stubs so multi-platform Blueprints compile and run cleanly in PIE without platform preprocessor guards.

Native OS UI & Battery Telemetry

Trigger native modal alert dialogs (ShowNativeAlertDialog), OS share sheets (ShowNativeShareSheet), and native toasts (ShowNativeToast) directly from Blueprint or C++.

Monitor live battery percentage, temperature in Celsius, charging state (EMobileBatteryChargeState), overheat alerts, and low-battery alerts via GetBatteryState(), SetBatteryAlertThresholds(), and OnBatteryStateChanged.
